# 런하이 디자인 기준

## 참고한 디자인

Figma 커뮤니티 파일 **“Mobile E-Learning App Design” (BrainByte, Nam Design)** 의 요소를 러닝 앱에 맞게 옮겼습니다.
요청받은 노드 5개 중 표지·타이포그래피·화면 모음(홈·상세·목록) 3개를 확인했고, 나머지 2개는 Figma 무료 플랜의 API 호출 한도에 걸려 열지 못했습니다. 확인한 화면에서 공통 언어를 뽑아 썼어요.

| 레퍼런스 요소 | 런하이에서 |
|---|---|
| 보라 `#6D57FC` 브랜드, 남색 피처 카드 | 같은 보라를 브랜드로, 남색 `#1E234B`은 **배번 카드**(추천 번개)·레벨 카드·호스트 통계에 사용 |
| “Get Your **Best Course** Today!” 인사말 + 한 단어 강조 | 홈 “오늘은 **내 페이스**로 달려요” |
| 진한 머리 영역 위로 겹쳐 올라오는 흰 시트 (상세 화면) | 번개·크루·대회 상세의 `Hero` + `SheetBody` (모서리 32px) |
| 파스텔 정사각형 썸네일 + 제목 + 메타 + 화살표 목록 | 번개 행(페이스 타일), 크루 행(크루 이모지 타일), 대회 행(날짜 타일), 예상 페이스 타일 |
| 연보라 진행 막대 | 번개 정원, 회비 납부율 |
| 빈 원 + 길쭉한 알약 페이지 점 | 온보딩, 레벨 계산까지 남은 인증 횟수 |
| 둥근 흰 재생 버튼 | 배번 카드의 이동 버튼, GPS 측정 시작 버튼 |
| Urbanist 숫자 | 페이스·거리·시간 숫자 (`font-num`), 한글은 Pretendard |
| Iconly 곡선 아이콘 | `react-iconly`(곡선, 선택 시 굵게) + 같은 선 굵기로 그린 번개·경로·GPS 아이콘 |

러닝 앱에만 있는 요소:
- **배번 카드**: 레이스 배번처럼 페이스 숫자를 가장 크게. 러너가 번개를 고를 때 가장 먼저 보는 정보라서.
- **페이스 게이지**: 내 예상 페이스와 목표를 한 줄에 놓고 여유(초록)·도전(주황, +30초까지)·무리(빨강) 구간을 보여 줌. 색만으로 뜻을 전하지 않도록 아이콘과 “목표보다 9초 느려요” 같은 문장을 함께 씀.
- **트랙 레인 장식**: 진한 머리 영역에 육상 트랙 곡선을 얇게.

## 색 (`apps/web/src/styles/index.css`)

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--brand` | #6D57FC | #8D7BFF | 주요 버튼, 선택, 강조 |
| `--navy` | #1E234B | #0A0C1D | 피처 카드, 머리 영역 |
| `--bg` / `--surface` | #F7F6FD / #FFFFFF | #0F1124 / #181B35 | 배경 / 카드 |
| `--ink` / `--ink-2` / `--muted` | #17142E / #4A4763 / #6B6886 | #F3F2FB / #C6C4DC / #8F8DAB | 글자 3단계 (모두 배경 대비 4.5:1 이상) |
| `--ok` / `--warn` / `--bad` | #0F9D74 / #C08400 / #DB2F55 | #3DD39F / #FFB547 / #FF6B72 | 판정·상태 채움(막대·점·게이지), 아이콘·문구와 함께 |
| `--ok-ink` / `--warn-ink` / `--bad-ink` | #0C7A59 / #946300 / #C4244A | 위와 같음 | 연한 바탕 위 상태 글자 (4.5:1 이상) |
| `--on-brand` | #FFFFFF | #14102E | 보라 버튼 위 글자 |
| 파스텔 | butter · peach · mint · sky · rose (+ tint) | 어두운 tint | 타일 배경 |

상태색(ok·warn·bad)은 판정·경고에만 씁니다. 채움용 세 색은 색각 이상에서도 구분되는지 dataviz 검증 스크립트로 확인했고, 글자에는 같은 색을 어둡게 한 `-ink` 토큰을 써서 WCAG AA 대비를 맞췄어요. 차트 강조는 브랜드 한 색 + 회색(`--chart-muted`)입니다.

다크 모드는 `html[data-theme]`를 항상 실제 값(light/dark)으로 맞춰 두고(시스템 설정 따르기 포함), 토큰과 Tailwind `dark:` 변형이 같은 기준으로 바뀝니다.

## 컴포넌트 (`apps/web/src/components`)

`Button` · `IconButton` · `Card`/`Section` · `Badge`(판정·신뢰·인증 출처) · `Chip`/`Segmented`/`Tabs` · `Field`/`Input`/`Select`/`Toggle`/`Checkbox`/`PaceInput` · `Sheet`(모바일은 아래에서 올라오고 데스크톱은 가운데, 포커스 가둠·Esc·Android 뒤로 가기) · `TopBar`/`Hero`/`SheetBody`/`BottomBar` · `Tile`/`ListRow`/`ProgressBar`/`PagerDots`/`EmptyState`/`Callout` · `PaceGauge` · `RouteSvg`(지도 타일 없이 경로를 선으로) · `ColumnChart`/`StackedColumnChart` · `RegionPicker` · `PlacePicker`(장소 규칙 배지)

## 차트

- 주간 거리(내 기록), 주간 번개 성사(운영)만 차트로 그렸습니다. 나머지 수치는 숫자 타일로 충분해서.
- 막대 폭 24px 이하, 위쪽만 4px 둥글게, 강조 1색 + 회색, 막대마다 호버·포커스 툴팁, ‘표로 보기’ 제공, 누적 막대는 범례 포함.

## 화면 원칙

- 모바일 우선, 데스크톱(1024px 이상)에서는 왼쪽 메뉴 + 가운데 본문.
- 탭 루트(홈·피드·번개·크루·대회)에만 아래 탭 막대. 상세 화면은 아래에 행동 버튼 하나(참여·신청·저장).
- 숫자는 Urbanist, 정렬이 필요한 표·축만 고정폭 숫자(`tnum`).
- 문구는 사용자가 하는 일 기준의 짧은 해요체. 오류는 무엇이 잘못됐고 어떻게 고치는지를 말함.
- 접근성: 모든 아이콘 버튼에 이름, 키보드 포커스 표시, 시트 포커스 가둠, `prefers-reduced-motion` 존중, 색만으로 상태를 전하지 않음.
